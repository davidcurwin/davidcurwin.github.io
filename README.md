# Personal site (GitHub Pages + Jekyll)

## Quick publish
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload these files to the repo.
3. In **Settings → Pages**, deploy from `main` branch, folder `/ (root)`.

## Editing
- Edit the `.md` files (Markdown). GitHub Pages builds the site automatically.
- Styling lives in `assets/css/style.css`.

## Custom domain
- Add a `CNAME` file at the repo root containing your domain (e.g., `davidcurwin.com`).
- Then set the DNS records at your domain registrar to point to GitHub Pages.
